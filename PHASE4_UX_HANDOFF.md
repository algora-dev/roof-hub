# RoofHub Phase 4 Handoff: Site & Conversion Redesign

**Date:** 20 October 2026  
**Package:** Package B, Phase 4  
**Built on:** Package A + Phase 3 Smart Assistant

## Goal

Reframe RoofHub as **the roofing website for New Zealanders** and make the new product architecture visible without damaging the deep research/evidence system already earning search visibility.

RoofHub is not framed as homeowner-only. The site now explicitly remains useful to homeowners, builders, roofers, estimators and other building/property professionals.

## Main changes

### Homepage

`app/page.tsx` now leads with:

> New Zealand roofing answers, pricing and tools in one place.

The first screen provides:

- **Estimate a roof**;
- **Use measurements**;
- prominent **Ask RoofHub** input;
- no-measurements-required reassurance;
- source-backed evidence reassurance;
- simple-to-detailed positioning.

The evidence/methodology explanation remains on the homepage but appears after the user-value paths rather than being the primary proposition.

### Header/navigation

Primary navigation is now:

- Pricing
- Roof types
- Guides
- Tools
- **Estimate a roof** CTA

About remains accessible in the footer but no longer consumes premium primary-navigation space.

### Tools index

`/tools` now separates:

#### Quick tools

- Estimate a roof
- Ask RoofHub

#### Advanced tools

- Detailed roof estimator
- Roof area & measurement
- Roof pitch & quantities
- NZ roofing cost evidence

Professional users are explicitly invited to go directly to measured/advanced tools without being forced through a homeowner workflow.

### Research article journeys

Every structured research article now gets a contextual application block generated by `lib/article-actions.ts`.

Examples can prefill useful Quick Estimate context such as:

- new vs reroof;
- existing concrete tile/decramastic;
- corrugate;
- five-rib;
- pressed metal tile;
- tray/standing seam;
- originating article path.

The article sidebar now says:

> Don't have measurements? That's fine. Start with what you know...

instead of telling users to read evidence first and use a tool only when measurements exist.

Articles now expose three coherent next actions where appropriate:

- estimate/apply;
- use measurements;
- Ask RoofHub.

The existing evidence, source notes, structured research content and URLs remain intact.

### Quick Estimate contextual presets

`components/quick-estimate/QuickRoofEstimate.tsx` now accepts explicit URL context:

```text
?project=new|reroof
?product=corrugate|five-rib|pressed-metal-tile|tray-standing-seam|membrane|undecided
?existing=...
?from=/originating/article
```

Only explicitly supplied fields are prefilled. Existing RoofProject information remains available.

The Quick Estimate page is wrapped in React `Suspense` so the `useSearchParams` client behavior is safe for Next.js static rendering.

### Project enquiry

The generic contact form is no longer the primary commercial handoff.

`components/ProjectEnquiryForm.tsx` provides a separate project-help workflow with choices for:

- understanding a project;
- getting a written contractor quote;
- getting comparable quotes;
- reviewing an existing quote.

The form automatically carries the shared non-sensitive RoofProject so users do not need to retype roof information.

Partner sharing is an explicit separate checkbox. The user can contact RoofHub without consenting to contractor sharing.

The original general/corrections form remains on `/contact` for:

- corrections;
- source suggestions;
- general enquiries;
- tool feedback.

The existing `Pressed metal tile roof` topic is now an allowed contact topic, fixing the prior silent fallback to General enquiry.

### Positioning/copy

The default site description and About copy now explicitly include builders alongside homeowners, roofers and building professionals.

The footer closes with:

> The roofing website for New Zealanders.

### Tool/page context improvement

`pageKindForPath()` now correctly categorizes both section roots and child pages, for example `/pricing` as well as `/pricing/...`. This improves Assistant context on hub pages.

### Sitemap dates

Routes materially changed in this package have updated route-registry last-modified dates:

- `/`
- `/tools`
- `/contact`
- `/privacy`
- `/terms`

Research article evidence review dates were **not** falsely changed merely because the shared presentation/CTA component changed.

## SEO rule to preserve

Do not turn this redesign into a content deletion exercise.

Preserve:

- existing indexed/ranking URLs;
- article HTML content;
- evidence/source relationships;
- canonicals;
- structured data;
- research metadata;
- current pricing evidence distinctions.

The Phase 4 work changes hierarchy, navigation and next actions around the content rather than replacing the evidence architecture.
