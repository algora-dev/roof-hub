Date: 21 October 2026

This matrix documents why selected contractor material is useful and how RoofHub limits it. “Surfaced in high-intent searches” is a discovery signal only; it is **not competitor traffic proof**.

## Why project studies receive more weight than generic service copy

A project page that states the roof type, observed failure, work completed and project-specific outcome is more decision-useful than a page saying “we repair all roofs”. It still remains publisher-reported evidence. RoofHub records that distinction using `projectSpecific`, `evidenceType`, `confidence`, `commercialInterest` and `limitations`.

## Why contradictory sources are useful

RoofHub deliberately keeps examples that point in different directions when both are credible within their own conditions. For example:

- a persistent Decramastic leak can sometimes be resolved locally;
- a different Decramastic roof with widespread surface loss, rust-through and multiple leaks can plausibly be a reroof case.

The contradiction is not a problem. **The conditions explain the different solution.** That is exactly the decision support RoofHub should provide.
