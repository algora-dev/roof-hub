## How the checks ran

`npm test` runs content, research and math checks. This sandbox supplied the TypeScript compiler from its global installation because local project packages could not be installed. Normal development uses the project's existing TypeScript dev dependency after `npm ci`.

The layout check used the actual source components rendered through a minimal offline JSX-to-HTML harness and actual site CSS. Chromium displayed the HTML with external requests disabled. The screenshots therefore use available fallback fonts. The harness is not React/Next hydration and is not shipped as application code. It does not validate client events, Next image optimisation, email delivery or a deployed server.

## Still required in the normal build environment

Run `npm ci`, `npm test`, `npm run typecheck`, and `npm run build`. Package installation in this sandbox was blocked by network/DNS access, so a complete Next production build is not certified here.

On a preview deployment, check:

- Home title/hero, navigation, mobile drawer and skip link.
- All seven added routes and their titles, canonicals, Article schema and ordinary anchor links.
- Actual React interaction for all four inline calculators, including invalid input and plan/actual toggling.
- A contextual article enquiry and correction enquiry: topic/page should prefill safely and private email must remain server-side.
- Existing detailed estimator, save/import/export, new roof/reroof and quote submission.
- Actual form delivery with configured server credentials. No test email was sent from this sandbox.
- Production checker using the deployment's existing indexing setting. Do not enable or disable indexing as part of this patch without the owner's approval.

The source status `verified` means an observation matched its cited public page. It does not validate an invoice, establish current availability, certify a roof system or make a historical guide current.
