## Rule for agents

Do not reintroduce the rejected/generated roof thumbnail pack from earlier versions.

New images should only be added when:

1. there is a defined page/use case;
2. the image is reviewed for roof/building realism;
3. it clearly improves the page more than a clean typography/UI treatment would.
